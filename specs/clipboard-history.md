# Clipboard history

Keeps everything you copy (text, images, files) and pastes any of it back
with a shortcut and Return. Replaces: Paste, Maccy. Taken from Onyx.

## Brief

```markdown
# Clips

A clipboard history for one person: every copy is kept, searchable, and one keypress away from being pasted again.

## Replaces
Paste and Maccy, and copying the same thing twice.

## Main jobs
1. Open the history with a shortcut and paste an older item into the app I'm in.
2. Search the history by text, file name, or the app it came from.
3. Delete one item, or clear the whole history.

## Data
- ClipItem: id, kind (text, image, files), text (or file paths, one per line), image file name, date, app name
- Images: PNG files in Application Support/Clips/clips, named by content hash

## Shape
Floating panel opened with a global shortcut, a menu bar extra, and a Settings window.
macOS 26 or later. Menu-bar-only (LSUIElement). Local data. Works offline. No accounts.

## System hooks
Global shortcut (default Option-Command-C), menu bar item, paste into the front app.

## Reference
Maccy, Paste

## Look
Native. One Liquid Glass panel: the list on the left (320 pt), a preview on the right,
the system accent color on the selected row.

## Not in version one
- Sync between Macs
- Pinned items and pinboards
- Rich text: text keeps only its plain string
- Editing an item before pasting
```

## How it works

| Part | API | Permission |
| --- | --- | --- |
| Watch the clipboard | `Timer` polling `NSPasteboard.general.changeCount` every 0.5 s | None |
| Read an item | `readObjects(forClasses: [NSURL.self], options: [.urlReadingFileURLsOnly: true])`, `data(forType: .png / .tiff)`, `string(forType: .string)` | None |
| Source app | `NSWorkspace.shared.frontmostApplication?.localizedName` | None |
| Global shortcut | Carbon `RegisterEventHotKey` | None |
| Panel that keeps the other app in front | `NSPanel` with `.nonactivatingPanel` | None |
| Paste into the front app | write `NSPasteboard`, post Command-V with `CGEvent` to `.cgSessionEventTap` | Accessibility |
| Thumbnails | `CGImageSourceCreateThumbnailAtIndex` | None |
| Menu bar item | `MenuBarExtra` | None |

Recipes: [Global hotkey](../skills/code/os-integrations/recipes.md#global-hotkey-carbon),
[Non-activating panel](../skills/code/os-integrations/recipes.md#non-activating-panel).
Signing that keeps the Accessibility grant: [os-integrations](../skills/code/os-integrations/SKILL.md#signing-keeps-grants).

Types to create:

- `ClipItem` (Codable, with `preview` and `filePaths`) and `ClipboardHistory` (`@Observable`: poll, read, dedupe, trim, save; `copy`, `delete`, `clear`).
- `Storage`: JSON in `~/Library/Application Support/Clips`. `Pasteboard`: the own marker type and the skip list.
- `SyntheticEvents` (Command-V with a marker) and `Permissions` (Accessibility state, polling, open the pane).
- `ClipsPanel` (`@Observable`: search, selection, `paste(item, pasteIntoApp:)`), `ClipsView`, `ClipRow`, `ClipPreview`, `ClipThumbnail`.
- `HotkeyCenter`, `KeyCombo`, `ShortcutRecorder`, `SettingsView`.

Exact behavior:

- Poll every 0.5 s with `tolerance = 0.1`, added to `RunLoop.main` in `.common` mode. Return early when `changeCount` did not change; store the new count before any other check.
- Skip the copy when the types include any of: the app's own type (`com.<you>.clips.internal`), `org.nspasteboard.TransientType`, `org.nspasteboard.ConcealedType`, `org.nspasteboard.AutoGeneratedType`, `com.agilebits.onepassword`.
- Read in this order, first hit wins: file URLs, PNG, TIFF (convert to PNG with `NSBitmapImageRep`), string. Skip a string that is only whitespace.
- Image file name: the first 12 bytes of the SHA256 of the PNG, as hex, plus `.png`. Write only when the file is missing. Store PNG data as it came.
- Add: remove any item with the same kind, text, and image file, then insert at the top. The same copy twice moves to the top.
- Limit: default 200, choices 50, 100, 200, 500, 1000, never under 10. Trimmed items delete their PNG when no other item uses it.
- Save 1 s after the last change (cancel the earlier save), to `clipboard.json`. Load once at start.
- Search: case-insensitive `localizedCaseInsensitiveContains` on the preview or the app name. Preview: trimmed text, "Image", or file names joined with ", ".
- Copy back: `clearContents()`, then text with `setString`, an image as PNG and TIFF, files with `writeObjects` of `NSURL`s. The poll then sees the same content and moves it to the top. That is the behavior you want.
- Paste: copy back, hide the panel, check `AXIsProcessTrusted()`, then post Command-V 0.06 s later. Without Accessibility the item stays on the clipboard and the app asks for the permission.
- Keys: Up, Down, Return pastes, Command-Return copies only, Command-Delete deletes, Command-1 to 9 pastes that row, Esc closes. Double-click pastes.
- Panel: glass 780 by 480 pt, 60 pt margin for the shadow, top 16% below the top of the screen with the mouse. Rows 38 pt. Image rows also show the relative time, since every image reads "Image".
- Preview: text in a monospaced, selectable scroll view; an image scaled to fit; files with icon, name, and folder. Footer: app name, relative date, and the Return, Command-Return, Command-Delete hints.

Posting Command-V. Mark the event so your own tools can skip it, and set the
flags yourself:

```swift
static let marker: Int64 = 0x434C_4950   // "CLIP"

static func paste() {
    let source = CGEventSource(stateID: .privateState)
    source?.userData = marker
    for down in [true, false] {
        let event = CGEvent(keyboardEventSource: source, virtualKey: CGKeyCode(kVK_ANSI_V), keyDown: down)
        event?.flags = .maskCommand
        event?.setIntegerValueField(.eventSourceUserData, value: marker)
        event?.post(tap: .cgSessionEventTap)
    }
}
```

## Gotchas

- Password managers mark copies with `org.nspasteboard.ConcealedType` (1Password also with `com.agilebits.onepassword`). Without the skip list, passwords end up in a plain JSON file.
- Your own helper writes (a snippet expansion, a one-off paste) must carry the app's own type and `TransientType`, or they flood the history. Copying an item back is not marked on purpose, so it moves to the top.
- Re-encoding a large screenshot PNG stalled the app. Store PNG data as it came; only convert TIFF.
- Read order matters. A Finder copy has file URLs, a file name string, and an icon TIFF. Check file URLs first and PNG before TIFF, or a file shows up as text or as its icon.
- A timer in the default run loop mode stops while a menu is open. Add it to `RunLoop.main` with `.common`.
- Post Command-V 0.06 s after hiding the panel. The panel is non-activating, so the other app never lost focus, but the key event must arrive after the panel is gone.
- The panel was slow to open: 17.5 ms main thread block warm, 112.5 ms first frame cold. No `makeFirstResponder` in `present()`, focus the field one run loop turn later, build the panel 2 s after launch. Result: 4.1 ms and 36.5 ms.
- Rows are 24 pt, so never load the full PNG for a row. Make thumbnails with `CGImageSourceCreateThumbnailAtIndex` (max 96 px) off the main thread and cache them in an `NSCache`.
- An ad hoc signed build loses the Accessibility grant on every rebuild, and paste silently does nothing. Sign with one stable certificate and install to the same path.

Done when copying text, a screenshot, and a Finder file each adds one item, Option-Command-C then Return pastes the chosen item into TextEdit, a 1Password copy never appears, and the history survives a restart.
